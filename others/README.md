## Before submitting the reports

Both PDFs currently have placeholder byline fields — **`[Author Name(s)]`,
`[Department, Institution]`, `[Course Code / Title, Instructor]`, and
`[Submission Date]`** — at the top of the title block. Fill these in before
submitting.

The reports are generated from editable HTML/CSS source, not written directly
as PDF, so you can edit and regenerate them:

```bash
npm install                        # one-time, pulls in Playwright
npx playwright install chromium    # one-time
npm run reports:build              # regenerates both PDFs into this folder
```

Source: `support/reports/final_report.html`, `support/reports/update_report.html`,
and the shared `support/reports/ieee_style.css`.
